# Changelog

## v1.0.0 - Initial Release

- Initial release of SSH Commander
- One-tap SSH connect with saved connections
- Saved commands for quick execution
- Live system stats monitoring (CPU, memory, disk, load, uptime, processes)
- Docker container controls
- Interactive terminal with tabbed interface
- Dark Material Design 3 theme with neon glow effects
- Room database for persistent storage
- Debug logging system with error codes (same pattern as VoiceMemo)
- Connection management (add, edit, delete, favorite)
- Quick action buttons for common commands
- Settings screen with About, Version, Check For Updates, and Share
- GitHub Actions workflows for debug and release builds
